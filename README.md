# Footstep_Energy_Converter
prototyped the japan technology of converting footsteps into energy . Here we used a peizosensor to generate voltage . We used arduino and an led bulb to proove tht each tap on the peizo actually generates voltage spikes . It can be seen in the serial plotter in Arduino IDE .Serial plotter shows ADC value vs time graph.
In reality we cannot produce large amount of voltages with just one peizo hence we need to use n number peizo to get the desired voltage .
It can be implemented in crowded areas to light street lamps etc.
